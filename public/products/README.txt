Tips
- Portrait photos work best (4:5, e.g. 1200 x 1500 px).
- Keep each file under about 500 KB. Next.js resizes them for phones automatically.
- Until a photo exists, the site shows a patterned placeholder.
- For new products, add the photos here, then enter the path (e.g. /products/wanjiru-1.jpg)
  in Admin > Products.
